# L1Q1-algorithm

## Aim
Arrange the given functions in increasing order of growth for a sufficiently large value of n.

## Algorithm

1. Start.
2. Read a sufficiently large value of n.
3. Compute the logarithmic value of each given function.
4. Store each function along with its computed value.
5. Sort the functions in ascending order based on their values.
6. Display the sorted order of the functions.
7. Stop.

## Time Complexity
O(k log k), where k is the number of functions.
