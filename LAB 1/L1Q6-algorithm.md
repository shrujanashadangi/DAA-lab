L1Q6-algorithm

## Aim
Determine whether duplicate elements exist among randomly generated numbers.

## Algorithm

1. Start.
2. Read the number of elements and the range.
3. Generate random numbers.
4. Sort the array.
5. Compare every element with its adjacent element.
6. If two adjacent elements are equal, report that duplicates are present.
7. Otherwise, report that all elements are unique.
8. Stop.

## Time Complexity
O(n log n)
